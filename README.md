# Codex Stream Helper

将本机 Codex 桌面版任务的回答同步到 OBS 的透明浏览器来源。你继续在 Codex 里工作，控制台负责选择任务、预览字幕和调整样式。

**按消息同步，默认每 1.8 秒读取一次。** 它显示已保存的回答，不提供逐字输出镜像。

## 功能

- 搜索、分页浏览本机任务，或通过任务 ID 连接。
- 独立的透明输出页，可作为 OBS「浏览器」来源。
- 聊天气泡与纯字幕两种样式；可调整字号、不透明度、强调色和保留消息条数。
- 显示模型、思考等级和速度，例如 `astra·极高·快速`。
- 支持暂停同步、清屏，以及进度消息和 CODEX 标识开关。
- 自动保存所选任务与样式设置，服务重启后恢复。
- Node.js 原生 HTTP / SSE 实现，无第三方运行依赖。

## 快速开始

需要 **Node.js 22 或更新版本**，以及已登录、能读取本机会话的 Codex。没有第三方运行依赖，也不需要额外 API Key。

```sh
git clone git@github.com:zch4321/codex-stream-helper.git
cd codex-stream-helper
npm start
```

仓库访问需要对应的 GitHub 权限。已经取得项目源码时，直接在项目目录执行 `npm start`；无需先运行 `npm install`。

- 控制台：<http://127.0.0.1:4318/>
- OBS 透明输出：<http://127.0.0.1:4318/overlay>

先打开 Codex 桌面版，再启动此服务，有助于自动选中与桌面版匹配的后端。保持运行 `npm start` 的终端开启；按 `Ctrl+C` 停止服务。

## 接入 OBS

1. 打开控制台，选择要显示的任务。
2. 点击「复制 OBS 地址」。
3. 在 OBS「来源」中添加「浏览器」，填入 `http://127.0.0.1:4318/overlay`。
4. 将宽度设为 `1280`，高度设为 `720`，再按需要在场景中拖动或缩放。

输出页本身没有背景，控制台的棋盘仅用于预览。样式和任务选择会自动同步到所有已打开的输出页；可以关闭控制台标签页，但需要保持本地服务运行。

这一步只添加显示来源，不会启动 OBS 推流。

## 工作方式

```text
Codex 桌面版 → 本地会话存储
                    ↓
独立 Codex App Server（thread/list、thread/read）
                    ↓ 每 1.8 秒读取一次
Node.js 本地服务 → SSE → 控制台预览 / OBS 透明网页
```

服务只调用 `initialize`、`thread/list` 和 `thread/read`，不会调用 `thread/resume` 或 `turn/start`。会话正文由 App Server 读取，只将 assistant 的公开回答和可选进度文字送到网页，不发送用户输入、推理内容或工具详情。

CODEX 标识旁显示当前任务的配置，例如 `astra·极高·快速`。模型和思考等级来自 `thread/read`；当后端没有返回速度字段时，根据它提供的当前会话文件路径，只读增量提取 `thread_settings_applied` 中的设置。此适配不搜索或合并分片，也不解析其中的消息。无法取得的字段会省略，不会按延迟推测速度。标签表示当前任务的已保存设置，不代表每条历史消息的实际执行配置；关闭 CODEX 标识时也会隐藏标签。

字幕是**按消息同步**：消息写入会话之后才会出现，不保证逐字显示。独立后端读到的任务状态不等于桌面实例的运行状态，所以界面只显示连接和同步状态，不把 `interrupted` 等历史快照状态误报为任务中断。

只显示本机后端可读取的任务；远程主机、云端任务和未同步到本机的数据不包含在内。读取长会话会有额外开销：当前实现使用完整快照，采用串行轮询避免并发堆积，发生错误后延长重试间隔。App Server 是实验性接口，特定分页存储能否读取取决于对应 Codex 版本。

目前已在 Windows 与 Codex 桌面版内置后端上验证。macOS / Linux 的后端查找路径已提供，但尚未完成端到端验证。

## 操作

- **选任务**：立即显示其最近几条回答，并更新 OBS 输出。
- **暂停同步**：冻结当前消息；样式仍可调整。恢复后显示最新消息。
- **清屏**：隐藏当前任务已有消息；之后新增的消息继续出现。切换任务会清除这条任务的清屏边界。
- **样式**：气泡 / 纯字幕、字号、气泡不透明度、强调色、保留条数，以及标识 / 进度开关。
- **长消息**：容纳不下时显示消息的末尾；网页不会出现滚动条。

设置和所选任务保存在项目的 `.local/settings.json`，已被 Git 忽略。它不保存会话正文。服务只监听 `127.0.0.1`，控制台和 OBS 应在同一台电脑上使用。

## 后端选择

Windows 上优先寻找正在运行的桌面版 App Server，再查找桌面版安装的运行时，最后回退到 PATH 中的 `codex.exe`。macOS 会尝试桌面应用内置后端；其他环境回退到 PATH 中的 `codex`。

桌面内置后端可能比独立 CLI 更新。遇到协议或存储兼容错误时，显式指定**与桌面版匹配**的可执行文件：

```powershell
$env:CODEX_BINARY = 'C:\path\to\desktop-runtime\codex.exe'
npm start
```

其他可选环境变量：

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `CODEX_BINARY` | 自动查找 | 指定 Codex 后端可执行文件 |
| `PORT` | `4318` | 本机 HTTP 端口 |
| `POLL_INTERVAL_MS` | `1800` | 读取间隔，最小 500 毫秒 |
| `CODEX_HOME` | Codex 自身默认值 | 指定已有 Codex 会话目录，原样传给后端 |

例如，在 PowerShell 中更换端口和读取间隔：

```powershell
$env:PORT = '4320'
$env:POLL_INTERVAL_MS = '2500'
npm start
```

更换端口后，也需要更新 OBS 中的输出地址。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 提示找不到 Codex | 先启动桌面版，或设置 `CODEX_BINARY` 为其内置后端路径。 |
| 任务没有出现在列表中 | 点击刷新、加载更多，或使用「通过任务 ID 连接」。任务需要保存在当前本机的 Codex 存储中。 |
| 控制台正常，但 OBS 未更新 | 确认来源使用 `/overlay` 地址、端口正确，并且本地服务仍在运行；刷新 OBS 浏览器来源。 |
| 消息要等一段时间才出现 | 字幕在完整消息写入会话后更新，再加上轮询间隔；当前不是逐字流式输出。 |
| 模型标签缺少速度或思考等级 | 后端或会话记录没有提供对应字段时会省略，不会猜测。 |
| 启动时提示端口被占用 | 使用已启动的控制台，或通过 `PORT` 指定其他端口。 |
| 读取失败或协议不兼容 | 优先设置与桌面版匹配的 `CODEX_BINARY`。不支持的会话存储格式会显示读取错误。 |

## 开发与测试

```sh
npm run dev
npm test
```

`npm run dev` 在服务端源码变化时自动重启；修改前端文件后刷新页面即可。项目不需要构建步骤。

测试覆盖只读接口白名单、协议分块、消息过滤、任务切换时的请求竞争、暂停与清屏、配置标签、分片路径变化和本地 HTTP / SSE 行为。不会调用真实模型。

## 项目结构

```text
src/codex-rpc.mjs       后端发现、JSON-RPC 连接和只读方法白名单
src/messages.mjs        消息过滤与设置校验
src/runtime-profile.mjs 模型、思考等级和速度的显示元数据
src/broadcast.mjs       轮询、选取任务、暂停与清屏
src/server.mjs          本地 HTTP / SSE 服务
public/                控制台和透明字幕页面
test/                  协议与行为测试
```
